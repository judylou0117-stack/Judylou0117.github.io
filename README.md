# Judy · 路遥 — Personal Portfolio

Finance foundations. AI possibilities.

路遥（Judy Lu）的个人作品网站：实习与科研经历、AI 项目（PauseBeforeBuy、UiPath 财务流程自动化、Tea Balance）以及生活。

- 托管：GitHub Pages
